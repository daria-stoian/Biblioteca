# BiblioWeb

Aplicatie web pentru gestionarea unei biblioteci.

## Structura depozitului

| Folder | Versiune | Tehnologii |
|---|---|---|
| `version-dotnet/` | 1.0 | ASP.NET Core MVC, Entity Framework Core, SQL Server, Identity |
| `server/` | 2.0 - API REST | Node.js, Express, Prisma, PostgreSQL, JWT |
| `client/` | 2.0 - interfata | React, Vite |

## Rulare versiunea 1.0
Se deschide `version-dotnet/Biblioteca.slnx` in Visual Studio si se porneste proiectul (necesita SQL Server LocalDB).
